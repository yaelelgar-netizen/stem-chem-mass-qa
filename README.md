# לומדת מסה — מדידות מסה בתחנת העגינה על פני הירח (STEM, כיתה ז׳)

לומדה אינטראקטיבית (HTML/CSS/JS) בעברית (RTL), חבילת **SCORM 1.2**, ציון מעבר 80.
יחידה שנייה, המשך ל[לומדת הנפח](https://github.com/methodicelElearnig/STEM_Chem_1_Volume).

- **נקודת הכניסה (SCO):** `index.html`
- **מבנה:** 28 מסכים (`data-screen="1..28"`) — סרטוני דמויות עם כתוביות, מסכי תוכן/דיאלוג,
  8 שאלות אינטראקטיביות (חד-ברירה, רב-בחירה, תפריטים נפתחים), שני יישומונים, ומסך סיום ששולח את הציון.
- **ניקוד:** 8 שאלות × 12.5 = 100. דיווח ל-LMS דרך `js/scorm.js`.
- **נגישות:** WCAG 2.1 AA / ת״י 5568 — ניווט מקלדת, פוקוס נראה, `prefers-reduced-motion`.
- **תרגום:** כל הטקסט "חי" בתוך ה-DOM וניתן לחילוץ. ראו `translation/`.

## מצב נוכחי
- **סרטונים (שקפים 2-3, 15, 28) טרם הופקו.** המסכים 1, 10 ו-20 מציגים כרגע את תמונת הרקע
  ואת הדיאלוג ככתוביות חיות. כשהסרטונים יגיעו יש להחליף את גוף המסך בנגן (ראו `.videoscreen`
  ב-`styles.css` ואת `initVideo` ב-`script.js`) ולהעביר את הטקסט ל-`<div class="vcap-src">`.
- **רקע חסר אחד:** למסך 2 (שקפים 4-5) אין פלייט נקי; בשימוש זמני `Gfx/5.png` בתור `bg-4.jpg`.
