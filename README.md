# לומדת מסה — מדידות מסה בתחנת העגינה על פני הירח (STEM, כיתה ז׳)

לומדה אינטראקטיבית (HTML/CSS/JS) בעברית (RTL), חבילת **SCORM 1.2**, ציון מעבר 80.
יחידה שנייה, המשך ל[לומדת הנפח](https://github.com/methodicelElearnig/STEM_Chem_1_Volume).

- **נקודת הכניסה (SCO):** `index.html`
- **מבנה:** 28 מסכים (`data-screen="1..28"`) על במה קבועה 1920×1080.
- **ניקוד:** 8 שאלות × 12.5 = 100. דיווח ל-LMS דרך `js/scorm.js`.
- **נגישות:** WCAG 2.1 AA / ת״י 5568 — ניווט מקלדת, פוקוס נראה, `prefers-reduced-motion`.
- **תרגום:** כל הטקסט "חי" בתוך ה-DOM. מניפסט: 380 רשומות, 0 קטעים לא מכוסים.

## מה עוד פתוח
1. **סרטונים (שקפים 2-3, 15, 28) טרם הופקו.** מסכים 1, 10 ו-20 מציגים כרגע את תמונת
   הרקע ואת הדיאלוג ככתוביות חיות. כשהסרטונים יגיעו: להחליף את גוף המסך בבלוק
   `.videoscreen` (ראו `styles.css` ו-`initVideo` ב-`script.js`), להעביר את הטקסט
   ל-`<div class="vcap-src">` עם `data-t`, ולהחזיר `data-type="video" data-gate="video"`.
2. **`bg-7.jpg` (שקף 7) יוצא עם הכיתובים "כדור הארץ / ירח / חללית" צרובים בתמונה.**
   הכיתובים החיים שאמורים לשבת ב-(1032,684) (1269,710) (1575,741) הוסרו זמנית
   כדי למנוע כפילות — להחזירם ברגע שיהיה פלייט נקי.
3. **למסך 2 (שקפים 4-5) אין פלייט ייעודי.** בשימוש `bg-lab-dark.jpg`, וארבעת הקלפים
   הם נכסי הנפח (`card-*.png`) בהתאם למדריך האמנות (שימוש חוזר, לא הפקה מחדש).
4. **`end-button.png` צרוב "סיימתי"** בעוד התסריט (שקף 39) כותב "סיום" — להכריע.
5. `Gfx/16 V1` נבחר על פני `16 V2`; `13a` על פני `13a-1`.

## שינויים במנוע המשותף (מול לומדת הנפח)
`styles.css`, `script.js` ו-`js/scorm.js` הועתקו כמו שהם, פרט ל:
- רכיבי היחידה בסוף `styles.css` (דוח נתונים, טבלת נתונים, מסגרות מהבהבות, חקר דגימות, לשוניות).
- ב-`script.js`: `initSamples`, `initTabs`, קישורי מעבר בין מסכים, שער `deadend`
  (מסך 7 — אפשר רק לחזור), וחיווט כפתור הסיום במסך שאינו סרטון.
- **תיקון באג שקיים גם בלומדת הנפח:** `ArrowLeft` קרא ל-`next()` בלי לבדוק את מצב
  השער, כך שאפשר היה לדלג במקלדת על כל השאלות ולהגיע לסוף עם ציון 0.
  `next()`/`prev()` בודקים כעת את `disabled` של כפתורי הניווט. **כדאי להעביר את
  התיקון גם ליחידת הנפח.**
